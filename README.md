# KLA Semiconductor Image Restoration

Deep learning-based image restoration system developed for the **KLA Semiconductor Image Restoration Challenge**.

The model takes noisy/low-quality grayscale semiconductor images in `.npy` format and produces restored images in `.npy` format.

---

## 1. Model

The final trained model is a custom convolutional restoration network implemented in PyTorch.

### Model Configuration

* **Input:** Single-channel grayscale `.npy` image
* **Output:** Single-channel restored `.npy` image
* **Base channels:** 64
* **Residual blocks:** 10
* **Framework:** PyTorch
* **GPU acceleration:** CUDA
* **Model weights:** `weights/best.pt`

The trained checkpoint contains the model state and configuration required by the evaluation script.


```powershell
python -m pip install --upgrade pip
```

## Step 4 — Install PyTorch with CUDA 12.8

The CUDA-enabled PyTorch packages are installed from the official PyTorch CUDA 12.8 package index:

```powershell
python -m pip install torch==2.11.0+cu128 torchvision==0.26.0+cu128 torchaudio==2.11.0+cu128 --index-url https://download.pytorch.org/whl/cu128
```

## Step 5 — Install the remaining dependencies

The repository contains the complete `pip freeze` output from the training environment in `requirements.txt`.

Install the dependencies using the PyTorch CUDA index as an additional package source:

```powershell
python -m pip install -r requirements.txt --extra-index-url https://download.pytorch.org/whl/cu128
```

This allows the CUDA-enabled PyTorch packages specified in `requirements.txt` to be resolved correctly.

# 6. Running Inference

## Evaluation Script

`evaluate.py` is the main benchmarking entry point for this submission.

It is a standalone Python script and accepts exactly two required positional arguments:

1. Path to the test images directory
2. Path to the output directory

Run from the repository root:

```powershell
python evaluate.py <test_images_directory> <output_directory>
```

### Example

```powershell
python evaluate.py "C:\path\to\NoisyLR" "restored_outputs"
```

No modification of `evaluate.py` is required.

The script automatically loads:

```text
weights/best.pt
```

---

# 7. Inference Process

The evaluation script performs the following steps:

1. Loads the trained checkpoint from `weights/best.pt`.
2. Automatically detects CUDA when available.
3. Discovers all `.npy` images in the supplied test directory.
4. Loads each input image.
5. Normalizes the input using the scale stored in the checkpoint.
6. Runs the restoration model.
7. Converts the prediction to a NumPy array.
8. Applies a safety clamp to the output range `[0, 1]`.
9. Saves the restored image as a `.npy` file.
10. Reports the number of processed images and average inference time.

The output filename corresponds to the input filename.

For example:

```text
Input:
000001.npy

Output:
000001.npy
```
